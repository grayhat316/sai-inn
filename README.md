# Sai Inn Hotel website

A complete hotel website: rooms, restaurant menu with ordering, events,
gallery, guest moments, journal, notices, and a full admin panel that controls
every word and photo on the site.

**Stack:** PHP 8 (no framework, no composer), SQLite, plain HTML/CSS/JS.

## Deploy

### Render (free, deploys from GitHub)
1. Push to this repository — everything at the root is the website.
2. In Render: **New → Blueprint**, pick this repo. `render.yaml` sets it up.
3. Add one secret env var in the Render dashboard: `SAI_ADMIN_PASSWORD`
   (the admin username is `admin`, or set `SAI_ADMIN_USER` too).
4. Visit the URL: the site installs its content snapshot on first request and
   creates the admin account from that password.

Service name in `render.yaml` decides the address: `sai-inn.onrender.com`.

Note on the free plan: the service sleeps after ~15 minutes idle (first visit
then takes about a minute to wake) and its disk is temporary, so bookings and
uploaded photos do not survive a redeploy. Use it for review and demos.

### cPanel (Kenyan shared hosting, the production home)
1. Upload the repo contents into `public_html` (or clone with cPanel's
   **Git Version Control**, then use *Update from Remote* to deploy changes).
2. Set PHP 8.0+ in **Select PHP Version**.
3. Make `data/` and `uploads/` writable (755).
4. Open the site once, then change the admin password in Admin → Settings.
CloudLinux + LiteSpeed/cPanel runs `.htaccess` as-is, so clean URLs work with
no extra configuration.

## Local development

```
php -S 127.0.0.1:8321 router.php      # http://localhost:8321, admin at /admin/
python make_seed.py                   # refresh seed/content.json after content edits
```

Pages are generated by `C:\Users\User\fridah\gen_sai_pages.py` (edit the
generator, re-run it, never hand-edit generated pages). `index.html` is the one
hand-maintained page.

## Layout

```
index.html, rooms.html, dining.html, ...   public pages (generated)
css/, js/                                  styles and front-end scripts
api/                                       PHP endpoints (public + admin)
admin/                                     dashboard (HTML/CSS/JS)
seed/                                      content snapshot installed on first boot
router.php                                 dev-only clean-URL router for php -S
.htaccess                                  Apache rewrite + hardening (prod)
Dockerfile, docker-entrypoint.sh           container image for Render
```

## Not in the repository

`data/` (the SQLite database with bookings and orders), `uploads/` (guest
photos), and `api/secrets.php`. Those live on the server. `seed/content.json`
carries only the site's own content: rooms, menu, offers, journal, notices.
